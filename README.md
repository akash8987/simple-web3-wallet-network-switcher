# Simple Web3 Wallet Network Switcher

This is a beginner-friendly Web3 project.

This project helps you:
- Connect a crypto wallet
- Switch blockchain networks
- Detect current network
- Learn how wallet network control works

This project uses:
- HTML
- JavaScript
- MetaMask API

## Features
- One-click wallet connect
- Button to switch network
- Show current network name
- Simple and clean code

## Requirements
- MetaMask installed
- Internet connection
- Basic JavaScript knowledge

## How to Run
1. Download this repository
2. Open `index.html` in browser
3. Click "Connect Wallet"
4. Click "Switch Network"
5. Approve in MetaMask

## File Structure
- index.html -> Main webpage
- app.js -> App logic
- config.js -> Network settings
- connect.js -> Wallet connect
- network.js -> Network detection
- switch.js -> Network switch logic
- ui.js -> Screen updates
- validate.js -> Checks
- logger.js -> Logs
- utils.js -> Helpers

## Learning Goal
This project helps beginners learn:
- How wallets manage networks
- How Web3 apps talk to MetaMask
- How chain switching works
